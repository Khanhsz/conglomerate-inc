# Conglomerate Inc. (tên tạm)

Game quản lý mô phỏng kinh doanh đa ngành, lấy cảm hứng từ Coffee Inc 2. Repo này hiện chứa bộ spec cho Milestone 1 và chuỗi prompt để phát triển cùng Claude Code.

- `CLAUDE.md` — quy tắc dự án cho Claude Code
- `docs/GDD.md` — thiết kế game
- `docs/economic-model.md` — đặc tả mô hình kinh tế (nguồn sự thật cho công thức)
- `docs/specs/M1-sim-core.md` — spec Milestone 1
- `docs/adr/` — quyết định kiến trúc
- `packages/content/` — dữ liệu ngành và scenario
- `prompts/README.md` — chuỗi prompt cho Claude Code, bắt đầu từ prompt 00
- `.claude/` — subagent, lệnh tùy chỉnh, hook

Bắt đầu: mở terminal ở thư mục repo, chạy `claude`, bật plan mode và dán prompt 00 trong `prompts/README.md`.
